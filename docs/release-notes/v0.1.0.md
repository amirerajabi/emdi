**Install**
- **Windows x64:** `Emdi-Setup-0.1.0.exe`. Markdown files (`.md`, `.markdown`, `.mdx`…) can then be opened with Emdi from Explorer.
- **macOS (Apple silicon):** `Emdi-0.1.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Emdi-0.1.0-linux-x86_64.AppImage`.

**The first release: a beautiful Markdown viewer**
- GitHub-flavoured Markdown: tables, task lists, footnotes, alerts (`> [!NOTE]`), emoji, definition lists, ==highlights==, sub- and superscript, and YAML front matter shown as a table.
- Highlighted code blocks with a copy button, KaTeX math (`$…$`, `$$…$$`) and Mermaid diagrams.
- Right-to-left text (Persian, Arabic, Hebrew) reads right-to-left, paragraph by paragraph.
- An explorer for a folder of Markdown files, an Outline of the document's headings, Find in Files, and "On this page" beside the text.
- Tabs with preview tabs, Search Everywhere (double Shift: files, `>` actions, `#` headings), Find in the document (Ctrl+F), Recent Files (Ctrl+E).
- Links to other Markdown files open in Emdi at the linked heading; local images are shown; web links open in the browser.
- Documents reload when they change on disk.
- Reading mode (F11), zoom (Ctrl+= / Ctrl+-), page width, reading fonts (sans, serif or your own), line spacing and numbered headings.
- Kod's light and dark themes, code themes, Settings with search, keyboard shortcuts, Export to PDF and Print.
- Updates itself from GitHub Releases, like Kod: downloads in the background, then "Restart to update".
