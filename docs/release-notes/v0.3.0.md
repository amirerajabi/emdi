**Install**
- **Windows x64:** `Folio-Setup-0.3.0.exe`. Emdi 0.1.x and 0.2.x update themselves to Folio.
- **macOS (Apple silicon):** `Folio-0.3.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Folio-0.3.0-linux-x86_64.AppImage`.

**Emdi is now Folio**
- A new name and a new icon: an F whose bars read as lines of text.
- Updating from Emdi keeps everything: your settings, theme, recent files and folders, open tabs, window size and spelling dictionary come along on the first start.
- On Windows the update replaces Emdi in place, so you won't end up with both apps installed. The Start menu and desktop shortcuts are now called Folio.
- The project moved to github.com/amirerajabi/folio; the old address redirects there.
