**Install**
- **Windows x64:** `Emdi-Setup-0.2.0.exe`. Emdi 0.1.x updates itself to this version.
- **macOS (Apple silicon):** `Emdi-0.2.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Emdi-0.2.0-linux-x86_64.AppImage`.

**Write Markdown: a full editor**
- Every document can be viewed, edited, or edited beside a live preview (**Split**) that scrolls with the text. The switch is on the right of the tab bar; Ctrl+/ toggles View and Edit, Ctrl+Alt+1 / 2 / 3 picks a mode. Alt+click a paragraph of the preview (or double-click it in Split) to edit it there.
- A **formatting toolbar**: Text / Heading 1–6, bold, italic, strikethrough, highlight, inline code, link, bulleted / numbered / task lists, quote, a code block by language, a table by size (grid picker), images, alerts, Mermaid diagrams, math, divider, and More (footnote, collapsible section, sub- and superscript, table of contents, front matter, date, Format Table).
- Type **`/`** for the same blocks as a menu, grouped with icons and filtered as you type (`/tab` → Table). Every item is also in Find Action ("Insert: Table").
- Lists and tasks continue on Enter, and a second Enter ends the list. Tab / Shift+Tab indent; Ctrl+Enter checks a task.
- Tables: Tab and Shift+Tab move between cells (a new row after the last one); Format Table lines the columns up.
- Paste a URL over selected text to make a link. Paste or drop an image to save it next to the document (in `images/`) and link it.
- Find and Replace, undo history per document, right-to-left lines, and spell checking with suggestions on right-click.
- Shortcuts: Ctrl+B, Ctrl+I, Ctrl+K (link), Ctrl+E (inline code), Ctrl+Shift+X (strikethrough), Ctrl+Shift+H (highlight), Ctrl+0 / Ctrl+1…6 (text / headings), Ctrl+Shift+7 / 8 / 9 (numbered / bulleted / task list), Ctrl+Shift+. (quote), Ctrl+Alt+C (code block).

**Files**
- New document (Ctrl+N), Save (Ctrl+S), Save As (Ctrl+Shift+S) and Save All.
- Auto Save a moment after you stop typing (or when Emdi loses focus, or off). Tabs show unsaved changes, and closing a tab or the window with unsaved changes asks first.
- The Explorer creates Markdown files and folders, renames (F2) and deletes (Delete, to the Recycle Bin / Trash). Open tabs follow a rename; a deleted file's unsaved edits stay open as a new document.

**Settings**
- New **Settings › Editor**: how Markdown files open and new documents start, Auto Save, the image folder, the toolbar, the `/` menu, spell checking, word wrap, line numbers, scroll sync and the editor font.
